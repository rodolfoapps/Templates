# SaaS Landing template

Product landing page: hero with product mock, logo cloud, feature grid, three-tier pricing, testimonials, FAQ and a final CTA.

## Customise

| What | Where |
| --- | --- |
| All copy, nav, pricing, FAQ | `src/site.config.ts` |
| Brand colours & fonts | `src/app/globals.css` (`@theme` block) |
| Favicon | `src/app/icon.svg` |
| Sections | `src/components/*` |

Run locally from the repo root: `pnpm --filter tpl-saas-landing dev`
