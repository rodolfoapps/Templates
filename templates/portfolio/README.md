# Portfolio template

Dark, minimal studio/personal portfolio: oversized hero, project grid, numbered services list, about with client list, and an email-first contact section.

## Customise

| What | Where |
| --- | --- |
| Copy, projects, services, clients | `src/site.config.ts` |
| Brand colours & fonts (dark by default) | `src/app/globals.css` (`@theme` block) |
| Favicon | `src/app/icon.svg` |
| Sections | `src/components/*` |

Run locally from the repo root: `pnpm --filter tpl-portfolio dev`
