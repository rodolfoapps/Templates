# Client mockups

Each folder here is a client-specific copy of a template, created with:

```bash
pnpm new:client <client-slug> <template-slug>
```

Each client gets its own Vercel project (Root Directory `clients/<client-slug>`), so it has its own preview URL to share and can later get the client's custom domain.

Folders are gitignored-free on purpose: commit client mockups so they deploy automatically.
